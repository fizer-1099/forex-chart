# Forex Chart

## ۱) فرستادن روی GitHub با Termux
```
pkg update && pkg install git gh unzip
termux-setup-storage
cd ~ && unzip ~/storage/downloads/forex-chart-app.zip && cd forex-chart-app
git init -b main && git add . && git commit -m "init"
gh auth login
gh repo create forex-chart --public --source=. --push
```
در GitHub: Settings ← Pages ← Source = **GitHub Actions**. بعد از چند دقیقه آدرس `https://USERNAME.github.io/forex-chart/` فعال می‌شود.

## ۲) نصب روی اندروید (PWA، پیشنهادی)
آدرس را در Chrome باز کنید ← منوی سه‌نقطه ← **Install app** (افزودن به صفحه اصلی). مثل یک اپ مستقل باز می‌شود و اعلان پس‌زمینه هم کار می‌کند.

## ۳) سرور (دیتا و هشدار پس‌زمینه)
۱. کلید رایگان از twelvedata.com بگیرید.
۲. کلیدهای اعلان: `cd server && npm install && npx web-push generate-vapid-keys`
۳. روی Render.com (یا Railway/Fly): New Web Service از همین ریپو، Root Directory = `server`، Build = `npm install`، Start = `node index.js`، و متغیرها:
   `TD_KEY`، `VAPID_PUBLIC`، `VAPID_PRIVATE`، `VAPID_SUBJECT` (مثلاً mailto:you@gmail.com)
۴. آدرس سرویس را در `app/config.js` بگذارید و `git add . && git commit -m srv && git push`.
۵. در اپ: پنل «هشدار» ← «اعلان پس‌زمینه» ← اجازه اعلان را بدهید.

نکته: دیسک پلن رایگان Render موقتی است و هشدارهای ذخیره‌شده با ری‌استارت سرویس پاک می‌شوند.

## ۴) فایل APK (اختیاری)
GitHub ← Actions ← **Android APK** ← Run workflow. بعد از چند دقیقه فایل `app-debug.apk` را از Artifacts دانلود و نصب کنید.
توجه: نسخه APK اعلان پس‌زمینه (Push) ندارد، چون به Firebase نیاز دارد. برای هشدار پس‌زمینه از نسخه PWA استفاده کنید.

## ۵) دیتای عمیق‌تر
با سرور فعال، دکمه «دیتای زنده API» تایم‌فریم پایه (s30، m1، m5، m15، m30، h1، h4، d1) و تعداد روز را می‌پرسد.
- فارکس، طلا، نقره، شاخص‌ها و نفت: از Dukascopy (چندین سال، بدون کلید). `s30` از دیتای تیکی ساخته می‌شود و حداکثر ۳ روز است.
- BTCUSD و ETHUSD: از Binance (حتی بدون سرور).
- اگر منبع بالا جواب ندهد، Twelve Data (حداکثر ۵۰۰۰ کندل) استفاده می‌شود.
بعد از تغییر سرور: `git push` کافی است، Render خودکار دوباره می‌سازد.

## نسخه ۲۰
کشیدن مستقیم خطوط SL/TP، محافظ اخبار (هشدار و بستن خودکار)، ربات تلگرام، خطوط جلسات فقط برای امروز. جزئیات در `mt5-bridge/README-VPS.md`.

## نسخه ۲۱
نوار ثابت مدیریت معامله زیر چارت، پوزیشن‌های باز در صفحه معامله، انتخاب سرویس هوش مصنوعی (OpenAI، DeepSeek، سرویس‌های ایرانی و...)، تنظیم تلگرام (از جمله کانال) از داخل اپ. جزئیات در `mt5-bridge/README-VPS.md`.

## نسخه ۳۰
رفع خطای prompt() در نسخه ویندوز (پنجره‌ی داخلی برنامه)، پر شدن خودکار کندل‌های جامانده بعد از خاموش بودن صفحه یا رفتن برنامه به پس‌زمینه، و ذخیره‌ی کتابخانه نمودار داخل برنامه (APK، Pages و ویندوز) برای بالا آمدن سریع‌تر.

## نسخه ۲۹
نسخه ویندوز (Electron، فایل portable بدون نصب) با GitHub Actions ساخته می‌شود: `gh release download latest-windows -p ForexChart-Windows.exe`. کتابخانه نمودار داخل نسخه ویندوز ذخیره می‌شود (بدون وابستگی به CDN).

## نسخه ۲۸
SL/TP خودکار برای معامله‌های بدون SL/TP، معامله خودکار بعد از هشدار EMA، قوانین ریسک (سقف معامله باز، ضرر روزانه، ریسک هر معامله)، ذخیره تنظیمات ریسک و حجم و اعمال روی صفحه معامله، حالت دلاری برای SL/TP و نمایش سود/زیان دلاری روی خطوط چارت.

## نسخه ۲۷
رنگ جدا برای بدنه و کادر کندل (سبک MT4)، رفع فاصله/کندل اضافه بعد از تغییر نماد یا تایم‌فریم، بارگذاری بسیار سریع‌تر (۳۰۰۰ کندل اولیه + بارگذاری تاریخچه با اسکرول + کش + فشرده‌سازی).

## نسخه ۲۶
هشدار EMA/SMA چند جفت‌ارز روی سرور (جایگزین اکسپرت EMA_MultiPair_Alert) با تنظیمات داخل اپ.

## نسخه ۲۵
اعلان تلگرام برای باز شدن، بسته شدن (TP/SL/دستی/بخشی) هر معامله؛ باز کردن معامله جدید از روی چارت با وجود پوزیشن باز و جابه‌جایی بین چند پوزیشن یک نماد؛ رفع افتادن کادر TP/SL روی دکمه پوزیشن‌ها.

## نسخه ۲۴
تریلینگ استاپ روی سرور، اعلان تلگرام برای TP/SL، حجم خودکار از درصد ریسک.

## نسخه ۲۳
انتخاب MT4 یا MT5 از داخل اپ (منو ← اتصال MT4 / MT5)؛ پل هر دو را همزمان نگه می‌دارد (`MT_PLATFORM=both`). هشدار قیمت و محافظ اخبار هر پلتفرم جدا کار می‌کنند.

## نسخه ۲۲
شمارش معکوس کندل زیر برچسب قیمت روی محور سمت راست (مثل TradingView). پشتیبانی از متاتریدر ۴ با اکسپرت `mt5-bridge/mt4/FxBridge.mq4` (`MT_PLATFORM=mt4`). جزئیات در `mt5-bridge/README-VPS.md`.
